# Colour

## Intents

Each intent (`accent`, `neutral`, `success`, `warning`, `danger`, `info`) has the same roles. Use the
role that matches what you draw: `-solid` for filled controls, `-on-solid` for text on them, `-subtle`
for tinted backgrounds, `-fg` for coloured text and icons, `-border` for outlines. They follow the
toolbar's theme and accent.
