# Elevation

Shadows for surfaces that float above the page: menus and popovers use `md`, dialogs `xl`.

Stacking uses the layer tokens, never hard-coded z-indexes: `--pada-z-base`, `-raised`, `-sticky`,
`-dropdown`, `-overlay`, `-modal`, `-popover`, `-toast`, `-tooltip`.
