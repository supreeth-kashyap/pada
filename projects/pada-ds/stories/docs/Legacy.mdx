# Legacy & migration

Pada 2.x keeps every 1.x component API working. Deprecated components are grouped under **Legacy**
(React only) and are removed in 3.0.

| Deprecated | Use instead |
| --- | --- |
| `Modal` | `Dialog` (`Dialog.Root`, `Dialog.Content`, `Dialog.Title` …) |
| `SideDrawer` | `Drawer` (`Drawer.Content side="right"`) |
| `Loader` | `Spinner`, `ProgressCircle` or `Skeleton` |
| `Notification` | `Toaster` and `toast()` |
| `FormLabel` | `Field` (`Field.Root`, `Field.Label`, `Field.Control` …) |
| `Logo` | `BrandLogo` (Pada's own logo is `PadaLogo`) |
| `Button split` / `onSplitClick` | `SplitButton` |

## Token names

The 1.x token names still work as aliases. A codemod renames them in your code:

```bash
npx pada-tokens-migrate src/ --dry-run   # list the changes
npx pada-tokens-migrate src/             # rewrite in place
```

The full upgrade guide is `docs/migration-2.0.md` in the pada repository.
