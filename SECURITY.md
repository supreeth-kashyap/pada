# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/supreeth-kashyap/pada/security/advisories/new).

Include what you found, the version of `pada-ds` affected, and steps to reproduce. You should get a
reply within a week. Once a fix is released, the advisory is published with credit to you unless
you'd rather stay anonymous.

## Supported versions

Only the latest release receives security fixes.
